Long-form guide studio

GTA 6 is about to make a lot of millionaires. Story-driven long-form videos hold their value and keep earning for years. This mode sets up a project in which Claude Code researches the niche, writes and fact-checks the script, voices it with ElevenLabs, builds the edit from official footage (via Apify), and grades every cut with fresh critics before uploading it as unlisted.

How it works

  1. Study. Claude finds the outliers in the niche and how the best ones are structured, or pitches concepts of its own from what players are discussing this week.
  2. Story. It writes three storylines, keeps the fully sourced one, and checks every claim against official sources.
  3. Footage. Apify collects official trailers and gameplay into a tagged library, so everything on screen is real footage.
  4. Voice and music. ElevenLabs voices the script with one locked professional voice and scores it; cuts land on the beat.
  5. Build. Claude writes an exact edit spec and builds it from a reusable component library.
  6. Critics. Fresh critics grade every cut blind, a judge ranks the fixes, and the loop repeats until it holds up next to the best channels.

Runs on a computer in Claude Code, with your own ElevenLabs, Apify and YouTube Data API accounts (their usage is billed by them). Vice Desk sets up the project; Claude Code does the work.

AI model

Pick who writes, critiques and judges. Tap Get API key to sign in to the provider and create a key, then paste it here. Keys stay on this device and go only to that provider. Consumer subscriptions (ChatGPT Plus, Claude Pro) can't be used by other apps; these providers only allow API keys, billed per use.

Voice: ElevenLabs (optional)

With an ElevenLabs key the guide is voiced by a professional voice. Without one, a free Microsoft voice is used; on Android, the phone's own voice takes over if that can't be reached.

Settings

YouTube sign-in (fixes "Sign in to confirm you're not a bot")

YouTube sometimes blocks downloads until it sees a signed-in session. Vice Desk then sends that session's cookies with every request. They stay on this device. A spare Google account is safest.

Paste a cookies.txt instead

Export cookies for youtube.com with a "cookies.txt" browser add-on while signed in, then paste the whole file here.
